# Booking App

A booking application built with React that allows users to select cities, dates, manage guest details to look for a hotel through a structured, user-friendly interface. The app focuses on form validation, state management, and realistic data handling.

## Features

- Date selection with validation (check-in / check-out)
- Guest selection (adults and children)
- Form handling with validation feedback
- Centralized state management for booking data
- Simulated backend using a local JSON server
- Responsive layout optimized for desktop and mobile devices
- Live deployment for easy access and testing

## Technologies Used

- React
- JavaScript (ES6+)
- Material UI
- React Router
- Redux Toolkit
- Redux Saga
- Formik
- Axios
- Vite
- Vitest
- Deployed with Vercel

## Skills Practiced

- Managing global application state with Redux Toolkit
- Handling side effects and async logic using Redux Saga
- Building complex, validated forms with Formik
- Working with date pickers and date logic
- API communication using Axios
- Component-based UI development with Material UI
- Writing and running tests with Vitest and Testing Library

## What I Learned

- How to structure a more complex React application with multiple state layers
- Improved understanding of Redux Toolkit and Redux Saga for scalable state management
- Gained experience handling form validation and user input edge cases
- Learned how to simulate backend behavior during frontend development
- Practiced testing React components and user interactions
